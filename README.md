# NeuroFlow
NeuroFlow je mobilní aplikace navržená pro mladé lidi (15–20 let), která pomáhá zvládat stres, úzkost a digitální přetížení pomocí vědecky podložených somatických a dechových cvičení. Aplikace propojuje tělesnou práci, moderní neurovědu a principy jógy do strukturovaného 30denního programu.
